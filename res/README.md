# 에셋 폴더 안내

이 폴더에는 모바일 앱 빌드에 필요한 아이콘과 스플래시 이미지가 들어갑니다.

## 필요한 에셋

### 아이콘 (res/icon/)

#### Android
- `android/ldpi.png` - 36x36 px
- `android/mdpi.png` - 48x48 px
- `android/hdpi.png` - 72x72 px
- `android/xhdpi.png` - 96x96 px
- `android/xxhdpi.png` - 144x144 px
- `android/xxxhdpi.png` - 192x192 px

#### iOS
- `ios/icon-57.png` - 57x57 px
- `ios/icon-57-2x.png` - 114x114 px
- `ios/icon-72.png` - 72x72 px
- `ios/icon-72-2x.png` - 144x144 px

### 스플래시 스크린 (res/screen/)

#### Android
- `android/splash-land-ldpi.png` - 320x200 px
- `android/splash-land-mdpi.png` - 480x320 px
- `android/splash-land-hdpi.png` - 800x480 px
- `android/splash-land-xhdpi.png` - 1280x720 px
- `android/splash-port-ldpi.png` - 200x320 px
- `android/splash-port-mdpi.png` - 320x480 px
- `android/splash-port-hdpi.png` - 480x800 px
- `android/splash-port-xhdpi.png` - 720x1280 px

## 에셋 생성 도구

온라인 도구를 사용하여 한 번에 모든 크기의 아이콘을 생성할 수 있습니다:

- [Icon Generator](https://icon.kitchen/)
- [App Icon Generator](https://appicon.co/)
- [MakeAppIcon](https://makeappicon.com/)

## 참고사항

- 아이콘은 PNG 형식으로 제공해야 합니다
- 배경이 투명하거나 단색인 정사각형 이미지를 사용하세요
- 스플래시 이미지는 앱 로딩 중에 표시됩니다
